# FPL Manager Survey — Research instrument
### Internal brief: FALEAGUE AI market research  
*(Potential partnership use is internal only — do not name third-party brands in respondent-facing copy.)*

**Purpose:** Produce decision-grade insights on how FPLers consume information, use tools, and behave in China vs English markets — including how overseas content reaches Chinese platforms.

**Bias rule (important):**  
**Do not name Fantasy Football Scout (or other partner candidates) in any respondent-facing question, option, intro, or incentive.**  
Brand interest can be inferred later from unaided open answers + category behaviour (overseas sites / creators / local translations). A branded follow-up wave is optional after analysis.

**Fielding recommendation**
- **Languages:** English + 简体中文 (same question IDs)
- **Length:** ≤8 minutes / ~24 questions (drop optional blocks if needed)
- **Incentive:** optional prize draw (e.g. Faleague Insights Pro month / small league prize / generic “premium FPL tool trial”) — **no named third-party membership**
- **Target n:** 200 minimum usable · 500+ preferred (split CN / EN reported separately)
- **Channels:** WeChat groups / Moments, faleague.cn, Faleague site banner, X/Reddit FPL, mini-leagues, XHS if available *(partner communities only if they agree to unbranded framing)*
- **Privacy:** no sale of emails; aggregate reporting only; Entry ID optional and never public

**Reporting cut:** China / Greater China respondents vs Rest of World — do not pool blindly.

## Analysis plan (internal / CEO leave-behind)

Report in this order — keeps claims reliable and unbranded until coding:

1. **Sample composition** — geography, language, season tenure, rank band  
2. **Source map** — overseas sites/creators vs local translators vs WeChat/XHS (China vs RoW)  
3. **Translation bridge** — frequency of translated overseas tips (Q15) × how managers use them (Q16) × Q8 path  
4. **Unaided trust list (Q7)** — code open answers *after* fieldwork; only then measure any specific brand share  
5. **Job-to-be-done** — hardest GW decisions × willingness to pay  
6. **Packaging signal** — interest in attributed Chinese hub; trust conditions (Q19 / Q24–25)  
7. **Product signal** — FALEAGUE usage / gaps (if n allows)

**Safe claim shape:**  
*“Among surveyed Chinese-speaking managers, Y% regularly use overseas creators/sites, and Z% rely on local translated/rewritten posts on XHS/WeChat.”*  

**Avoid until unaided coding:** naming any single overseas brand’s awareness % from this wave.
