# 问卷星创建步骤 — FPL经理调研

导入文本已生成：`docs/wenjuanxing-import-zh.txt`（32题，中文，**不出现任何海外品牌名**）

## 一键流程（约5分钟）

1. 打开 https://www.wjx.cn/ 并**登录**（微信扫码最快）
2. 点 **创建问卷** → 选 **问卷调查**（不要选考试）
3. 标题建议：`FPL经理调研（约8分钟）`
4. 进入编辑页后，左侧找 **批量添加** / **导入文本**
5. 打开 `wenjuanxing-import-zh.txt`，**全选复制**，粘贴到导入框 → 解析/确定导入
6. 导入后检查：
   - 带【多选题】的题 → 确认题型为多选；Q3/Q6/Q10/Q17 设最多可选数量
   - 带【填空题】的题 → 确认是填空/简答
   - Q22 量表：若被识别成单选，可改成 **量表题** 0–10，或保留 0–10 单选
7. （可选）设置显示逻辑：
   - Q9：S3=仅英文 时可跳过
   - Q14–Q19：居住地为中国大陆/港澳台/新马，或语言为中文/双语时显示
   - Q21–Q23：Q20=经常/一两回 时显示
8. **发布** → 复制链接 / 二维码发到微信群

## 问卷开头说明（可粘到问卷说明区）

```

不出售个人数据；开放题仅用于汇总分析。感谢支持！
```

填完可留微信抽奖（可选）。链接：【粘贴问卷星链接】
